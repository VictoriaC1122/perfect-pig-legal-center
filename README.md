# 完美養豬 Legal Center

《完美養豬》官方四語法律與支援頁面。

內容包含：

- 隱私權政策
- 版權聲明
- 開發者聯絡入口
- 繁體中文、簡體中文、English、日本語切換

設計語氣延續 app 本身的奶油粉藍色系，並使用：

- `Playfair Display`
- `Manrope`
